Легковесный, высокопроизводительный аудиоплеер для Android с интеграцией VK Музыки, поддержкой радиостанций и эстетикой Apple Music.

---

## 🎯 Назначение

VK Tracks решает задачу удобного, быстрого и автономного прослушивания музыки из социальной сети ВКонтакте без рекламы, ограничений фонового режима и визуального шума:
* **Интерфейс:** Лаконичный дизайн в стиле Apple Music (Material 3 + кастомная стилизация, плавная бегущая строка Marquee, плавающий MiniPlayer, горизонтальные свайпы по обложке трека, пакетный выбор композиций и полноэкранный FullPlayerSheet с караоке-текстами и сворачиванием по свайпу вниз).
* **Среда выполнения:** Android 8.0+ (API 26+) для смартфонов, планшетов, автомобильных головных устройств (Android Auto, Pioneer Smart Sync).
* **Автономность:** Прямое воспроизведение MP3 и HLS (.m3u8), кэширование сетевых потоков на лету (ExoPlayer SimpleCache) и загрузчик аудио с вшиванием ID3v2-тегов и обложек в системную медиатеку `Music/VK Tracks/`.

## ✨ Особенности

* **Интеграция с Pioneer Smart Sync:** Регистрация в Android в качестве полноценного музыкального плеера (`APP_MUSIC`, `MUSIC_PLAYER`, `MEDIA_PLAY_FROM_SEARCH`). Управление с физических кнопок автомагнитол Pioneer, отображение метаданных и обложек по протоколам Bluetooth AVRCP.
* **Поддержка Android Auto:** Реализация `MediaLibraryService` и регистрация `MediaBrowserService`. Предоставление каталога для мультимедиа автомобиля: «Скачанное (Офлайн)», «Мои треки (Избранное)», «Текущая очередь», «Радио (Прямой эфир)» и поддержка голосового поиска Google Ассистента за рулём.
* **Автовоспроизведение и автопауза Bluetooth:** Автоматическое возобновление воспроизведения при подключении Bluetooth-устройства (с защитой от прерывания сторонних приложений) и мгновенная пауза при разрыве Bluetooth-соединения.
* **Микро-фейдинг (Soft Transitions):** Мягкое нарастание и затухание громкости (150 мс) при старте, паузе и переключении треков без модификации PCM и щелчков в динамиках.
* **Свайпы по обложке в плеере:** Быстрое переключение на следующий (свайп влево) и предыдущий (свайп вправо) трек по обложке в полноэкранном плеере с пружинной анимацией.
* **Пакетные операции в медиатеке:** Режим множественного выбора треков (долгое нажатие или кнопка «Выбрать»), массовое скачивание, удаление и добавление выбранных треков в плейлисты.
* **Надежный аудиодвижок Media3:** Фоновая служба `MediaSessionService`, полная интеграция с System Media Controls (шторка уведомлений и экран блокировки) с передачей обложек высокого разрешения, автономными действиями (лайки/сердечки без утечек памяти при закрытом интерфейсе) и аудиофокусом.
* **Контекстное меню трека:** Действия по клику на 3 точки в плеере и списках («Инфо о треке» с честным замером битрейта, «Поделиться», «Воспроизвести следующим», «Добавить в конец очереди», «Добавить в плейлист», кликабельные артисты с переходом к их трекам).
* **Управление плейлистами VK:** Создание новых плейлистов прямо из интерфейса медиатеки и диалога добавления трека с синхронизацией в аккаунте ВКонтакте.
* **Офлайн-вкладка «Мои треки» в Поиске:** Мгновенная локальная фильтрация по сохранённой библиотеке (избранное и скачанное) без сетевых задержек.
* **Нативный звуковой поиск Google:** Быстрый вызов музыкального оверлея «Включите или напойте мелодию» (Google Sound Search) прямо из строки поиска с автоматической паузой плеера для чистого захвата звука микрофоном.
* **Интерактивная очередь воспроизведения:** Ручное изменение порядка треков (вверх/вниз) и удаление элементов из очереди прямо в полноэкранном плеере.
* **Гибкие режимы кеширования:** Единый селектор режима кэширования («Все проигрываемые» / «Только избранные») с нативной потоковой буферизацией ExoPlayer (`DefaultLoadControl`) без блокировок и обрывов.
* **Каскадный резолвер обложек:** Нативные обложки VK API $\rightarrow$ In-Memory кэш $\rightarrow$ база данных Room $\rightarrow$ высокоскоростной API Яндекс Музыки (основной студийный источник 600×600 в РФ) $\rightarrow$ Apple Music/iTunes API (резервный контур). Защита Generic Guard исключает ложный поиск для безымянных треков.
* **Синхронизированные тексты песен (караоке):** Открытый API LRCLIB без геоблоков в РФ, парсинг стандарта LRC с точностью до миллисекунд, построчная подсветка текста в такт музыке, автоскролл и перемотка тапом по строке. Автоматическое офлайн-кеширование текстов в Room v9.
* **Интерактивные жесты:** Плавное сворачивание полноэкранного плеера по свайпу вниз (`Modifier.draggable`) с пружинной физикой возврата (`spring`).
* **Прямой эфир радио:** Радио «Studio 21» (WebSocket EMG + российские метасерверы) и «Record» (JSON API) со стабилизацией потоков без скрипов и аудио-артефактов.
* **Умная пагинация и 120 FPS:** Мгновенный отклик интерфейса, изолированные обновления состояний плеера, отсутствие лишних перерисовок и фрагментации памяти JVM (`android:largeHeap="true"`).
* **Синхронизация с серверами:** Избранное, персональная волна «VK Mix» с настройками, альбомы, плейлисты, поиск по исполнителям и трекам, синхронизация лайков.
* **Встроенный OTA-апдейтер:** Автономная система проверки и фоновой установки обновлений по воздуху через GitHub Pages CDN без сервисов Google Play.
