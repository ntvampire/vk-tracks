# Техническое задание: VK Tracks (Android)

## 1. Концепция и цель проекта
**VK Tracks** — легковесный, высокопроизводительный и функциональный музыкальный плеер под Android для экосистемы ВКонтакте.
Приложение сочетает в себе:
1. **Визуальный стиль и UX Apple Music:**
   - Строгая типографика, минималистичный интерфейс без визуального шума.
   - Фирменная акцентная палитра Apple Red (`#FA2D48`), полупрозрачные контейнеры (`SurfaceVariant`), скругления углов (12–20 dp), мягкие тени у обложек треков.
   - Стандартные паттерны взаимодействия: крупный динамический заголовок экрана, нижняя панель навигации (Bottom Navigation Bar), плавающий мини-плеер (MiniPlayer) с бесшовным открытием, полноэкранный смахиваемый плеер (FullPlayerSheet) с синхронизированным караоке-текстом и модальные экраны детального просмотра плейлистов и исполнителей.
   - Плавная бегущая строка (Marquee) для длинных названий треков и артистов в мини-плеере, полноэкранном плеере и очереди воспроизведения.
2. **Практический функционал VKX и Murglar (без перегруженности):**
   - Прямой доступ к аудиопотокам VK Music без ограничений фонового режима и без аудиорекламы.
   - Поддержка прямых MP3-потоков и адаптивных HLS (`.m3u8`) плейлистов с бесшовным кэшированием на лету.
   - Полная двусторонняя синхронизация с серверами VK (лайки/сердечки, плейлисты, история прослушивания, динамическая бесконечная пагинация медиатеки Избранного пачками по 100 треков).
   - Офлайн-кэширование аудиопотока через ExoPlayer `SimpleCache` с настраиваемыми лимитами хранилища (500 МБ – 10 ГБ) и LRU-вытеснением.
   - Автономный загрузчик треков в MP3 с автоматической сборкой сегментов HLS, вшиванием ID3v2 тегов и обложек высокого разрешения.
   - Сохранение скачанной музыки в общедоступную папку устройства `Music/VK Tracks/` через `MediaStore API` (Android 10+) с немедленной регистрацией в системном медиасканере `MediaScannerConnection`.
   - Отображение нативных обложек сервисов (VK API thumb/photo, Record, Studio 21). При отсутствии обложки у трека (null) отображается легковесная векторная нота (`Icons.Default.MusicNote`).
   - Высокоскоростной двухфакторный кэш обложек (In-Memory `ConcurrentHashMap` 0 ms + локальная БД Room).
   - Прямой эфир радио («Studio 21» и «Record») с динамическим парсингом метаданных на лету (WebSocket EMG, JSON API Record, потоковые ICY-теги) и передачей обложки/названия в системную шторку уведомлений (System Media Controls) и экран блокировки.
   - Быстрый запуск поиска по звуку Google Sound Search с каскадом интентов и смарт-кнопка быстрой вставки из буфера обмена.
   - Встроенная система автообновления по воздуху (OTA) через GitHub Releases и CDN-зеркало GitHub Pages с защитой фонового скачивания в Foreground Service.

## 2. Архитектура и стек технологий
- **Платформа:** Android (minSdk 26, targetSdk 34).
- **Язык разработки:** Kotlin 1.9+ (со строгой типизацией, Flow и корутинами).
- **UI фреймворк:** Jetpack Compose + Material 3 (кастомная стилизация под Apple Music, поддержка тёмной и светлой тем).
- **Аудиодвижок:** AndroidX Media3 (ExoPlayer 1.4+) в рамках системного сервиса `MediaLibraryService` (`PlaybackService`) с нативной поддержкой Android Auto, сохранением очереди и позиции воспроизведения (`QueueSaveHolder`), HLS с автовыбором 320 кбит/с (`HlsBitrateEstimator`) и санитаризацией файлов (`FileSanitizer`).
- **Сетевой слой:** OkHttp 4 + прямой REST-клиент VK API с поддержкой официального App ID VK Музыки / BOOM (`client_id = 6767438`).
- **Локальная база данных:** Room 2.6 (`AppDatabase`: таблицы `TrackEntity`, `PlaylistEntity`, `CoverCacheEntity`).
- **Кэширование потоков:** `SimpleCache` + `CacheDataSource` (AndroidX Media3) с изолированным хранилищем на диске и алгоритмом LRU.
- **Загрузка и рендеринг изображений:** Coil Compose (высокопроизводительный слоёный `Box` со стандартным `AsyncImage` и аппаратным ускорением скролла 120 FPS; нативная загрузка `album.thumb` через VK API v5.155 без серых квадратов; чистая векторная нота `Icons.Default.MusicNote` строго при отсутствии обложки; `android:largeHeap="true"`).
- **Тегирование аудиофайлов:** модуль `Id3Tagger` (бинарная запись заголовков ID3v2.3/2.4, текстовых фреймов TIT2, TPE1, TALB, TYER и фрейма обложки APIC).
- **OTA обновления:** сервис `UpdateDownloadService` (Foreground Service с `WakeLock`), парсер `update.json` и прямая установка через системный `PackageInstaller`.
- **Конфиденциальность и хранение:** `EncryptedSharedPreferences` (хранение `access_token` и `user_id`).

## 3. Функциональные модули системы

### 3.1. Модуль авторизации и аккаунта
- Авторизация через официальный OAuth VK (`oauth.vk.com/authorize` с `client_id=6767438` или через нативное приложение VK при наличии).
- Безопасное хранение токена доступа (`access_token`) и идентификатора пользователя (`user_id`) в `EncryptedSharedPreferences`.
- Поддержка быстрой валидации токена при старте приложения с тихим обновлением данных профиля (`account.getProfileInfo` / `users.get`).
- Гостевой/ограниченный режим: возможность слушать радио и общедоступные чарты даже без авторизации в аккаунте VK.
- Быстрый выход из аккаунта с очисткой токена и сбросом кэшированных списков.

### 3.2. Аудиодвижок и фоновое воспроизведение
- Полноценная фоновая работа через `PlaybackService` на базе `MediaSessionService`.
- Полная интеграция с системным медиаконтроллером Android 11+ (System Media Controls в шторке и на экране блокировки):
  - Передача метаданных трека (`title`, `artist`, `albumTitle`).
  - Передача высококачественной обложки в виде JPEG-байтов через `MediaMetadata.setArtworkData()`.
  - Динамическая кнопка «Сердечко» (Like/Unlike) прямо в шторке уведомлений с мгновенной синхронизацией медиатеки.
  - Поддержка кнопок перехода к предыдущему/следующему треку и плей/паузы.
  - Клик по карточке плеера в шторке гарантированно разворачивает полноэкранный плеер (`showFullPlayer` в `MainViewModel` через `ACTION_OPEN_PLAYER` и `launchMode="singleTop"`).
- Поддержка HLS потоков (`.m3u8`) и прямых MP3 потоков с бесшовным переключением.
- Режимы воспроизведения:
  - Shuffle (случайный порядок очереди с сохранением исходного списка).
  - Repeat (без повтора, повтор всей очереди, повтор одного трека `RepeatMode.ONE`).
- Защита аудиопотока от прерываний: обновление метаданных живого эфира радио (`updateLiveMetadata`) происходит без остановки и пересоздания декодеров ExoPlayer.
- Стабилизация радиовещания: явное задание MIME-типов (`audio/mpeg` для Studio 21, `audio/aac` для Record), принудительная фиксация скорости воспроизведения строго на 1.0f (`minPlaybackSpeed = 1.0f`, `maxPlaybackSpeed = 1.0f` в `LiveConfiguration`), исключающая работу алгоритма time-stretching Sonic (устранение скрипов, писков и высокочастотных артефактов), и адаптивный `DefaultLoadControl` с живыми порогами буфера (`minBufferMs = 15s`, `bufferForPlaybackMs = 1.5s`) против заиканий и опустошения буфера.
- Стабилизация перемотки: включение `constantBitrateSeekingEnabled(true)` в `DefaultExtractorsFactory` (расчёт смещений по битрейту для MP3/AAC без Xing-заголовков, устраняющий сброс таймлайна на 0:00 при первом клике), тайм-лок в `PlaybackService` (1.2 сек) и прямое удержание прогресса в `FullPlayerSheet` (`displayPosMs`, `dragFraction`).

### 3.3. Кэширование аудиопотока на лету (MediaCacheManager)
- Архитектура кэширования по подобию VKX и Murglar:
  - Прозрачный перехват запросов `DataSource.Factory` через `CacheDataSource.Factory`.
  - Дисковый кэш размещается в `context.cacheDir/media_stream_cache/`.
  - Автоматический обход кэширования для прямого эфира радио (Studio 21, Record, потоки с `duration == 0`), чтобы предотвратить забивание диска живым аудиопотоком.
- Настройки дискового кэша в разделе параметров:
  - Переключатель полного включения/выключения кэширования потоков.
  - Настройка максимального размера кэша (500 МБ, 1 ГБ, 2 ГБ, 5 ГБ, 10 ГБ).
  - Автоматическое вытеснение старых фрагментов по алгоритму LRU (`LeastRecentlyUsedCacheEvictor`).
  - Отображение текущего занятого размера кэша в мегабайтах/гигабайтах.
  - Кнопка немедленной очистки дискового кэша.

### 3.4. Офлайн-загрузчик и файловая подсистема
- Поддержка скачивания как прямых MP3-ссылок, так и потоков HLS (`.m3u8`):
  - Рекурсивный парсер плейлистов HLS с автоматическим извлечением мастер-плейлиста наивысшего битрейта.
  - Последовательное скачивание и бесшовная склейка аудио-сегментов `.ts`/`.aac` в единый контейнер MP3.
- Внедрение метаданных через модуль `Id3Tagger`:
  - Прошивка тегов ID3v2.3: Название трека, Исполнитель, Альбом, Год релиза.
  - Вшивание обложки альбома высокого разрешения в тело аудиофайла (фрейм APIC).
- Сохранение через Android MediaStore API:
  - Сохранение файлов в общедоступный системный каталог устройства `Music/VK Tracks/`.
  - Запись потока через `MediaStore.Audio.Media.EXTERNAL_CONTENT_URI` (устранение ошибки `EXDEV: cross-device link not permitted`).
  - Автоматическая регистрация нового файла в системной медиабазе Android через `MediaScannerConnection.scanFile`, благодаря чему скачанные треки сразу видны в любых сторонних аудиоплеерах и проводниках.
  - Сортировка по подпапкам: треки из плейлистов сохраняются в `Music/VK Tracks/[Название плейлиста]/`.
  - Отображение статуса скачивания на карточках треков (иконка галочки в зелёном круге) во всех списках приложения.

### 3.5. Мультиплатформенный каскадный резолвер обложек
- Многоуровневая архитектура получения студийных обложек:
  1. **Нативные обложки сервисов:**
     - **Треки ВКонтакте:** рекурсивный извлекатель `extractCoverUrl` (парсинг `album.thumb`, `photo_600`, `photo_300`, `photo_1200`, `photo_270`, `thumb`, `sizes`). Автоматическое наследование родительской обложки альбомов и плейлистов.
     - **Radio Record:** прямое поле `image600` из официального JSON-эфира радиостанции, при отсутствии — логотип станции `RadioStation.RADIO_RECORD.logoUrl`.
     - **Studio 21:** прямое поле `coverImageUrl` из официального WebSocket-потока холдинга EMG, при отсутствии — логотип `RadioStation.STUDIO_21.logoUrl`.
  2. **Двухуровневое кэширование:**
     - In-Memory кэш `ConcurrentHashMap` (0 мс доступ при скролле).
     - Локальная база данных Room (`coverUrl` в таблице `tracks`, миграция `MIGRATION_7_8` Room v8).
  3. **Защитный фильтр безымянных треков (Generic Guard):**
     - Строгая проверка `isGeneric(artist, title)`: запросы с `Unknown artist`, `Untitled`, `Без названия` и пустыми тегами блокируются до сетевых обращений, отдавая чистую векторную иконку ноты (`Icons.Default.MusicNote`) и предотвращая ложное сопоставление с чужими релизами.
  4. **Основной студийный источник в РФ — Yandex Music API (`YandexMusicApiClient`):**
     - Высокоскоростной endpoint поиска (`https://api.music.yandex.net/search?text=...&type=track`).
     - Время отклика <200 мс, отсутствие блокировок и WAF 403 в РФ, поддержка студийных HD-обложек 600x600.
     - Строгая верификация соответствия исполнителя и названия, фильтрация караоке/трибьютов.
  5. **Резервный контур — Apple Music / iTunes API (`ItunesApiClient`):**
     - Автоматический fallback при отсутствии совпадений в отечественном каталоге с контролем частоты запросов.
  6. **Векторная нота-заглушка:**
     - Чистая нота `Icons.Default.MusicNote` отображается только при действительном отсутствии обложки.
- Оптимизация списков Jetpack Compose: строгие ключи `key = { it.fullId }` во всех `LazyColumn`, аппаратный даунсэмплинг Coil до 144x144 px для миниатюр и изоляция очереди `currentQueue` внутри полноэкранного плеера для стабильных 60/120 FPS скролла.

### 3.6. Динамическая подгрузка медиатеки (пагинация)
- Модель постраничной загрузки `AudiosPage`:
  - `tracks: List<Track>` — список валидных распарсенных треков текущей пачки.
  - `totalCount: Int` — общее число аудиозаписей в медиатеке пользователя по данным VK API (`response.count`).
  - `rawCount: Int` — фактическое число элементов в ответе VK API (до фильтрации недоступных или удалённых треков).
- Точный учёт смещения API через `myAudiosOffset`: смещение инкрементируется на величину `rawCount` полученных элементов, что исключает сдвиги и зацикливание при наличии заблокированных в регионе записей.
- Двойной надёжный триггер подгрузки в Jetpack Compose:
  - Реактивный триггер `itemsIndexed` в `LazyColumn`: инициирует загрузку следующей порции (`onLoadMoreTracks()`) при попадании элементов хвоста списка (за 8 элементов до конца) в зону композиции с ключом `myTracks.size`.
  - Вспомогательный триггер `derivedStateOf` по состоянию прокрутки `LazyListState`.
- Защита от дублирования и гонок запросов: дебаунс `_isLoadingMoreTracks`, блокировка повторных вызовов во время сетевой активности.

### 3.6. Прямой эфир радиостанций (Studio 21 и Record)
- **Радио «Studio 21»:**
  - Официальный аудиопоток прямого вещания в высоком качестве.
  - Двухфакторное получение метаданных на лету:
    1. Прямое WebSocket-соединение с метасервером EMG (`meta.hostingradio.ru`).
    2. Fallback на российский HTTP-источник плейлиста без внешних блокировок.
    3. Потоковые ICY-теги (`StreamTitle`) из аудиопотока Icecast.
- **Радио «Record»:**
  - Официальный аудиопоток прямого вещания.
  - Периодический опрос API радиостанции (`radiorecord.ru/api/stations/now`) с извлечением названия, артиста и официальной обложки эфира.
- Защита от дублирования названия трека в поле исполнителя.
- Умная кнопка «Сердечко» для радио: клик по сердечку на экране радио переключает пользователя на вкладку «Поиск» и автоматически ищет играющий трек в каталоге VK Музыки.

### 3.7. Структура интерфейса (Apple Music Style)
1. **Вкладка «Слушать» (Listen Now):**
   - Интерактивный блок «VK Mix» (кнопка запуска персональной волны, модальный экран настроек настроения, темпа, языка и узнаваемости треков `VkMixSettingsSheet`).
   - Баннеры прямого эфира «Studio 21» и «Record» с бейджем LIVE и динамическими названиями текущих песен.
   - Секции персональных рекомендаций, миксов по артистам и жанрам.
2. **Вкладка «Медиатека» (Library):**
   - 4 подраздела: «Избранное» (Моя музыка VK), «Плейлисты», «Альбомы», «Скачанное».
   - Корректная фильтрация плейлистов и альбомов без ложных срабатываний.
   - Мгновенное открытие и отображение сохранённых локальных треков.
3. **Вкладка «Поиск» (Search):**
   - Авто-фокус на строку ввода при переключении на вкладку.
   - Кнопка запуска встроенного поиска по звуку Google Sound Search (`Icons.Default.GraphicEq`) с каскадом интентов (Google App, SoundSearchShortcut, Voice Assist, Shazam).
   - Смарт-кнопка быстрой вставки из буфера обмена (`Icons.Default.ContentPaste`).
   - 4 подвкладки результатов: «Треки», «Плейлисты», «Альбомы», «Исполнители».
   - Детальная карточка исполнителя (`ArtistDetailScreen`): фото, кнопка «Слушать все», топ треков и дискография релизов.
4. **Плавающий мини-плеер (MiniPlayer):**
   - Отображается над нижней панелью на всех экранах (включая открытые плейлисты, альбомы и карточки артистов).
   - Обложка, бегущая строка с названием и артистом, кнопки Play/Pause и Next.
   - Тап по мини-плееру открывает полноэкранный плеер.
5. **Полноэкранный плеер (FullPlayerSheet):**
   - Смахивание вниз (pull to dismiss) и жест закрытия.
   - Переключение между 3 режимами центральной области: «Обложка альбома», «Караоке-текст с автоскроллом», «Очередь треков».
   - Умное сердечко, бегущая строка, интерактивный слайдер таймлайна.

### 3.8. Система автоматического обновления (OTA)
- Автоматическая проверка новых релизов при старте приложения по файлу манифеста `update.json`.
- Прямое CDN-зеркало APK на GitHub Pages (обход блокировок и лимитов хранилищ).
- Фоновое скачивание обновления через Foreground Service (`UpdateDownloadService`) с уведомлением прогресса в шторке и `WakeLock`.
- Fallback-кнопка «Скачать через браузер» при сбоях встроенного установщика.

## 4. Требования к надёжности и оптимизации
1. **Принцип KISS:** Простые, прямолинейные решения без многослойных абстракций.
2. **Изоляция рендеринга Compose:** Переменные таймера прогресса воспроизведения (`currentPosMs` / `durationMs`) отслеживаются только внутри `FullPlayerSheet`, что гарантирует 0 лишних перерисовок корневых экранов и стабильные 60/120 FPS при скролле.
3. **Безопасность потоков:** Отсутствие фоновых лавинных запросов при открытии медиатеки; обложки подгружаются строго реактивно или отдаются из кэша.
4. **Защита конфиденциальных данных:** Никаких логов токенов; `.env` и локальные базы данных изолированы.

## 5. Функциональные блоки архитектуры
1. **Core Playback Engine:** Служба `PlaybackService`, сессия Media3, ExoPlayer с кэшем `SimpleCache`, управление аудиофокусом и медиа-нотификациями.
2. **Data & Repository Layer:** Единый источник истины `TracksRepository` (объединение VK API с Room `TrackDao` для гарантированного обогащения метаданных и обложек), `RadioRepository`, `CatalogRepository`.
3. **UI & Presentation Layer:** Jetpack Compose экраны (Библиотека, Поиск, Обзор), полноэкранный плеер `FullPlayerSheet`, мини-плеер `MiniPlayer`, модульные компоненты `TrackItem` и `TrackCoverThumbnail`.
4. **Radio & Live Metadata:** WebSocket EMG (Studio 21), REST API (Record), потоковый парсинг ICY-тегов, независимый жизненный цикл метаданных прямого эфира.
5. **Download & Storage Management:** Модуль `TrackDownloader` со сборкой HLS в MP3, записью тегов ID3v2 и регистрацией в общедоступном Android `MediaStore`.
